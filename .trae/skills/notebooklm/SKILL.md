# NotebookLM

Use this skill for source-grounded synthesis.

## When to use

Activate when the user wants to:
- summarize notes, PDFs, docs, transcripts, or web research
- combine multiple sources into one understanding
- create study guides, FAQs, glossaries, timelines, or briefing docs
- compare sources and identify agreements, conflicts, and gaps
- turn raw material into something easier to learn from or share

## Workflow

1. Identify the source set.
2. Extract the core claims, facts, definitions, and open questions.
3. Group related ideas into themes.
4. Preserve source grounding whenever possible.
5. Produce the output format the user actually needs.

## Good outputs

Prefer outputs such as:
- executive summaries
- topic-by-topic syntheses
- study guides
- Q&A / FAQ
- key takeaways with evidence
- comparison tables
- action-oriented briefings

## Quality bar

- separate facts from interpretation
- keep terminology consistent
- note uncertainty or source disagreement explicitly
- compress aggressively without losing the important distinctions

## If the user provides many sources

Start by proposing a structure like:
1. main themes
2. strongest findings
3. conflicts / ambiguities
4. concise final synthesis
