# v1.3.0 更新日志（草稿 · 待审核）

> 目标版本：v1.3.0（versionCode 130）
> 写入位置：`app/src/main/res/raw/changelog_entries.json`（插最前，`（当前版本）` 后缀从 v1.2.1 挪过来）

## 【新增】

· 正式上线闹钟功能：支持设置闹钟时间与标签，到点响铃提醒
· 正式上线待办功能：支持新增、勾选完成、左滑删除、编辑待办、清除已完成，误删除可撤销
· 待办支持按全部 / 未完成 / 已完成筛选，标题栏实时显示未完成数

## 【小组件】

· 新增闹钟桌面小组件（含标准、紧凑、倒计时三种形态）
· 闹钟小组件在系统添加页新增预览缩略图，所见即所得

## 【优化】

· 首页整体改版：常用功能改为列表展示，附带实时状态
· 首页点右侧爱心可置顶常用，置顶排最前面，重启后保留
· 首页点"全部"可弹窗查看所有功能
· 移除顶部导航栏与侧边栏，保留底部首页 / 我的导航，界面更简洁
· 定时返回页新增"上次时长"显示
· 统计页面布局与功能更新
· 待办行改为圆角卡片，对勾更小巧，撤销提示改为圆角
· 小贴士文案同步当前功能

## 【修复】

· 修复自定义时长弹窗偶发闪退
· 修复待办清除已完成按钮在无数据时可点的问题
· 修复多个对话框按钮可见性问题
