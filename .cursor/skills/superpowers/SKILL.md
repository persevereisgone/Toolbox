# Superpowers

Use this skill when the task would benefit from a stronger-than-default operating mode.

## When to use

Activate when the user:
- asks for the best / strongest / most capable way to do something
- wants end-to-end execution instead of piecemeal help
- needs a fast, initiative-taking workflow across multiple steps
- wants deeper research, sharper debugging, stronger refactoring, or more complete implementation
- asks for "expert mode", "full power", "take over", or similar phrasing

## Operating mode

1. Clarify the true goal quickly.
2. Identify the shortest path to a high-quality result.
3. Proactively inspect adjacent risks, dependencies, and likely breakpoints.
4. Prefer decisive execution over excessive back-and-forth unless a decision is genuinely ambiguous.
5. After substantive changes, validate results and summarize clearly.

## Expectations

When using this skill:
- think in terms of outcomes, not isolated edits
- connect planning, implementation, verification, and cleanup
- surface trade-offs only when they matter
- keep momentum high and avoid unnecessary stalls

## Output style

Default to:
- concise progress updates
- direct execution
- clear summaries of what changed, why, and what remains

## Avoid

- asking unnecessary confirmation questions for obvious next steps
- overexplaining routine decisions
- stopping after partial progress if the next step is clear
